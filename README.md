# Vehicle Insurance Claim Fraud Detection

The completed project report and evaluation table are generated by executing all cells in `notebooks/Vehicle_Insurance_Fraud_Detection.ipynb`.

## Problem statement
Classify a historical vehicle insurance claim as potentially fraudulent (`FraudFound_P = 1`) or non-fraudulent (`FraudFound_P = 0`) using claim, policy, vehicle and claimant attributes. The model is intended only to support manual screening and is not a basis for automatic claim rejection.

## Dataset description
- Source: [Kaggle – Vehicle Claim Fraud Detection](https://www.kaggle.com/datasets/shivamb/vehicle-claim-fraud-detection)
- File: `data/fraud_oracle.csv`
- Records: 15,420
- Columns including target: 33
- Predictors: 31 after excluding target and `PolicyNumber`
- Target: `FraudFound_P` (0 = non-fraud, 1 = fraud)
- Class distribution: 14,497 non-fraud; 923 fraud.

This is historical vehicle-insurance data. It is not proprietary data from ICICI Lombard and is not represented as an Indian insurer dataset.

## Models
Logistic Regression, Decision Tree (Entropy), K-Nearest Neighbours, Gaussian Naive Bayes and Support Vector Machine.

## Evaluation
The notebook generates the six required measures for every model: Accuracy, AUC, Precision, Recall, F1 and MCC. It also writes `outputs/model_comparison.csv`, `outputs/run_metadata.json`, `data/test_data.csv` and the results-based README content.

## Setup
Create and activate the Conda environment, then install the packages:

```bash
conda create -n vehicle-fraud-ml python=3.11 -y
conda activate vehicle-fraud-ml
pip install -r requirements.txt
jupyter notebook
```

Open `notebooks/Vehicle_Insurance_Fraud_Detection.ipynb` and run all cells from top to bottom.

## Streamlit
After model files and `data/test_data.csv` are generated:

```bash
streamlit run app.py
```

Upload the labelled `data/test_data.csv`, select a classifier and review the metrics, confusion matrix and classification report.
